# Branding

La aplicacion es una **herramienta academica no oficial**. No afiliada ni
mantenida por UNLaM.

- No redibujar ni inventar el logo institucional.
- Si se usa el logo oficial: conservar proporciones, no deformarlo, no
  presentar la app como producto institucional oficial.
- Incluir en "Acerca de": "Herramienta academica no oficial. No afiliada
  ni mantenida por UNLaM."
- Mientras no se consiga el asset oficial con certeza de origen, usar
  texto plano "UNLaM" (sin logo) - pendiente de reemplazo, documentado
  aca cuando se resuelva.
